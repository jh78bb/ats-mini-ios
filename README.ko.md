# ATS Mini Remote

[English](README.md) · **한국어**

iOS remote controller for ATS Mini radio receivers.

**ATS Mini Remote**는 iPhone에서 ATS Mini 라디오 수신기를 찾아 연결하고, 주파수와 볼륨을 조절하는 iOS 앱입니다. `ats-mini-ios`는 이 앱의 소스 저장소입니다.

**현재 상태** · 제어 화면 UI와 BLE 연결 코드를 구현했습니다. BLE 연결은 **실기기(iPhone + ATS Mini)에서 아직 검증하지 못했고**(시뮬레이터에는 블루투스가 없습니다), Wi-Fi TCP는 구현했고 저장소에 포함된 모의 수신기로 iOS 시뮬레이터에서 끝까지 확인했지만(*시뮬레이터에서 시험하기* 참고) 실제 수신기에서는 확인하지 못했습니다.

## 앱에서 블루투스로 연결하기

1. ATS Mini의 `Settings → Bluetooth`에서 `Ad hoc` 모드를 켭니다.
2. iPhone에서 앱을 열고 **기기 연결 → 블루투스**를 선택합니다. 처음 연결할 때는 iOS의 블루투스 접근을 허용합니다.
3. 앱에 표시되는 주변 수신기 목록에서 내 ATS Mini를 선택합니다.
4. 연결이 완료되면 제어 화면에서 주파수, 볼륨, 밴드와 수신 모드를 조절합니다.

한 번 연결한 수신기는 앱을 다시 켜면 자동으로 다시 연결하고, 연결이 끊겨도 자동으로 재시도합니다. 헤더의 ON/OFF 칩에서 연결 상태를 확인하고 해제할 수 있습니다.

## 연결 방식

| 방식 | 연결에 필요한 설정 | 개발 방향 |
| --- | --- | --- |
| 블루투스 LE (BLE) | 수신기의 `Bluetooth → Ad hoc` 설정과 iOS 블루투스 권한 | 기본 연결. 공유기나 IP 주소 입력 없이 앱에서 수신기를 찾아 연결합니다. |
| Wi-Fi TCP | 수신기의 Wi-Fi와 `TCP Port → Ad hoc` 설정, iOS 로컬 네트워크 권한 | 보조 연결. 구현했습니다. **기기 연결 → Wi-Fi TCP**에 호스트와 포트를 입력합니다(기본값 `atsmini.local`, 포트 `60000`). 시뮬레이터에서는 모의 수신기로 시험할 수 있습니다. |

수신기 가까이에서 바로 연결할 때는 BLE가 간편합니다. 집에서 수신기를 공유기에 연결해 두고 쓴다면 Wi-Fi도 편리합니다. ATS Mini 펌웨어 문서는 안정성을 위해 수신기의 Wi-Fi와 블루투스를 한 번에 하나씩 사용하도록 권장합니다. [ATS Mini 원격 제어 문서](https://esp32-si4732.github.io/ats-mini/remote.html) · [수신기 설정 안내](https://esp32-si4732.github.io/ats-mini/manual.html) · [iOS 로컬 네트워크 권한](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy)

## 제어 화면 UI

거의 검은 배경에 어두운 둥근 카드를 쌓는 세로 화면 UI입니다. 구성은 [Radio 앱 시안(GIF)](https://i.pinimg.com/originals/02/ae/b4/02aeb4bf8f22a177054f7e702493fa30.gif), 카드 스타일은 모노톤 대시보드 시안을 참고했고, 제어 항목은 [ATS-Mini-Companion](https://github.com/rodillo69/ATS-Mini-Companion)과 [ATS Mini Controller](https://atsminiradio.com/en)를 참고했습니다.

- **Now tuning 카드**: 가운데 빨간 포인터가 현재 주파수인 다이얼 눈금자를 좌우로 드래그해 스텝 단위로 튜닝합니다(눈금 간격은 FM 0.1 MHz, LW 1 kHz, MW/SW 10 kHz). 굵은 `101.70 MHz` 숫자, 좌우 `‹ ›` 버튼, 점선 박스의 밴드 표시, 모드·스텝 칩이 함께 있습니다.
- **상태 타일**: RSSI, SNR, 볼륨을 큰 숫자 타일로 보여줍니다. 볼륨 타일을 누르면 슬라이더(0~63)와 음소거 버튼이 있는 팝업이 열립니다.
- **버튼**: 흰색 알약 버튼으로 현재 주파수를 프리셋에 저장/삭제하고, 옆의 원형 버튼으로 음소거합니다. 연결 중에는 하트가 **수신기의 메모리 슬롯**에 저장/삭제하고, 연결하지 않았을 때는 앱에만 저장되는 프리셋을 만듭니다.
- **Signal 카드**: 신호 세기와 볼륨에 따라 움직이는 점 이퀄라이저(연출용)와 `LIVE` 상태. 음소거나 연결 해제 시 바닥만 남습니다.
- **하단 스테이션 바**: 현재 주파수와 일치하는 항목을 밝은 캡슐로 강조합니다. 연결 중에는 **수신기의 메모리 슬롯**(이름이 있으면 이름)을 보여주고, 연결하지 않았을 때는 앱에서 저장한 프리셋(기본값 없음)을 보여줍니다. 슬롯을 누르면 수신기를 그 슬롯의 밴드와 모드로 먼저 옮긴 뒤 주파수를 지정합니다.
- **Seek / Scan**(제어 화면, 수신기 연결 필요): ◀ ▶ 버튼은 튜닝 스텝만큼 한 칸씩 옮기며 선택한 감도(강/보통/약 = RSSI 30/20/10 dBµV, SNR 12/8/3 dB)를 넘는 다음 방송국에서 멈춥니다. Scan은 멈출 때까지 계속하며 방송국마다 약 4초 머뭅니다. 매 스텝의 신호는 상태 줄에서 읽으므로(스텝당 약 1초) 튜닝 스텝이 크면 더 빠르고, FM은 87.5–108 MHz를 훑습니다. 다이얼이나 화살표를 누르면 멈춥니다. Ad hoc 프로토콜에는 seek 명령이 없어서 앱이 직접 합니다.
- **헤더**: 햄버거 메뉴(맨 위에 기기 연결, 그 아래 밴드, 모드, 스텝, 볼륨. 연결 중에는 밴드를 수신기의 28개 밴드 목록(주파수 범위 표시)에서 고르고, 모드는 분할 버튼으로 고릅니다). 모든 항목의 제목 오른쪽에 **`?` 버튼**이 있어 무엇을 하는 항목인지 설명하고, 밴드 도움말에는 밴드마다 어떤 방송이 들리는지 짧은 설명이 있습니다, 톱니바퀴 버튼(고급 설정), ON/OFF 연결 칩.
- **고급 설정(톱니바퀴)**: 고급 사용자용 수신기 제어이며 수신기에 연결해야 동작합니다.
  - 대역폭(`W`/`w`), AGC/감쇠기(`A`/`a`), 보정(`I`/`i`) −/+ 버튼. 대역폭은 수신기가 알려 주는 실제 값을, AGC는 목록 순번을 함께 표시합니다. 각 항목에는 연결하지 않아도 눌러 볼 수 있는 `?` 도움말이 있습니다.
  - 슬립 켜기/깨우기(`O`/`o`).
  - 수신기 엔코더: 왼쪽/오른쪽 돌리기(`r`/`R`), 클릭(`e`), 길게 누름(`E`)으로 수신기 메뉴를 조작합니다.
  - 메모리 슬롯: 슬롯 99개 읽기(`$`, 연결 직후 자동으로도 읽음), 비어 있는 첫 슬롯에 현재 주파수와 이름 저장(`#`), 슬롯 지우기(주파수 0으로 `#` 전송, 확인창 있음), 슬롯을 눌러 그 주파수로 이동.
  - 통신 로그: 보낸 명령과 받은 줄, 마지막 상태 줄과 상태 줄 수신 횟수를 보여주며, 문제를 알릴 때 쓰는 복사 버튼이 있습니다.
- 기기에 연결하지 않은 동안에는 데모 값으로 동작하고(`OFF`), 연결하면 수신기가 보내는 상태로 값이 갱신됩니다(`ON`).

### 스플래시 화면, 앱 아이콘, 언어

- **스플래시**: 런치 스크린(앱 배경색과 같은 어두운 배경 + 다이얼 로고)에 이어 같은 위치의 로고와 앱 이름이 부드럽게 나타났다가 메인 화면으로 넘어갑니다. 로고와 앱 아이콘은 다이얼 눈금과 빨간 포인터 모양입니다.
- **언어**: 영어(기본)와 한국어를 지원합니다. iPhone의 언어 설정을 따르고, 문자열은 `ATSMiniRemote/Localizable.xcstrings`, 블루투스 권한 문구는 `ATSMiniRemote/*.lproj/InfoPlist.strings`에 있습니다. 새 언어는 같은 파일에 번역을 추가하면 됩니다.

### BLE 연동 구현

프로토콜은 [ATS Mini 원격 제어 문서](https://esp32-si4732.github.io/ats-mini/remote.html)를 따릅니다(USB 시리얼, BLE, TCP 공통).

- **연결**: Nordic UART Service(`6E400001-B5A3-F393-E0A9-E50E24DCCA9E`)로 검색해 연결합니다. 문서에 특성(characteristic) UUID가 없어서 notify 특성은 수신, write 특성은 송신으로 속성을 보고 찾습니다. 한 번 연결한 기기는 앱을 다시 켜면 자동으로 재연결하고, 끊기면 자동으로 재시도합니다. 헤더의 ON/OFF 칩이나 메뉴의 `기기 연결`에서 수신기를 고릅니다.
- **상태 수신**: 연결 후 `t`(로그 토글)를 보내 15개 필드 상태 줄을 받아 화면에 반영합니다. 펌웨어 v2.45 소스로 확인한 사실: 13번 필드는 문서의 설명(ADC 정수)과 달리 배터리 전압을 소수(`4.05`)로 보내고, 스텝과 대역폭 필드는 `100k`, `2.5k` 같은 문자열입니다. 앱에 표시되는 밴드 이름(`VHF`, `31M` 등)과 모드는 이 줄에서 가져옵니다. `Error: Frequency is out of range for the current band` 같은 오류 응답은 짧은 메시지로 보여줍니다. 재연결 직후에는 로그가 꺼져 있어, 상태 줄이 오지 않을 때만 `t`를 보냅니다.
- **제어**: 다이얼·화살표·프리셋은 `F<Hz>`(주파수 직접 지정), 볼륨은 `V`/`v`, 밴드는 `B`/`b`, 모드는 `M`/`m`을 보냅니다. 주파수 명령을 보낼 때마다 상태 줄로 적용됐는지 확인하고, 수신기가 움직이지 않았으면 엔코더 회전(`R`/`r`, 수신기가 알려 준 스텝 기준)으로 다시 시도하며, 그것도 안 되면 표시를 원래대로 되돌리고 메시지를 보여줍니다. 방금 설정한 주파수는 오래된 상태 줄로 덮어쓰지 않습니다. SSB 모드의 주파수는 `kHz×1000 + BFO`로 표시합니다. 다이얼을 드래그할 때는 명령이 쏟아지지 않도록 120 ms마다 최신 값만 보냅니다.
- **미구현**: 수신기 화면 스크린샷(`C`/`c`)과 테마 읽기/설정(`@`/`^`)은 아직 연동하지 않았습니다. 스크린샷은 BMP 대용량 전송(BLE에서 약 30초)과 이미지 디코딩 검증이 필요하고, 실기기 없이는 확인할 수 없기 때문입니다.
- **밴드 목록**: 수신기에는 밴드 목록을 알려 주는 명령이 없어서, 펌웨어 v2.45 소스의 `bands[]` 표(`VHF`, `ALL`, `11M` … `CB`)를 그대로 옮겼습니다. `B`는 이 순서대로 넘어가므로, 앱은 가까운 방향으로 `B`/`b`를 한 칸씩 보내고 매번 상태 줄로 확인합니다. `15M`은 표에 두 번 나오므로(방송용, 아마추어용) 현재 주파수로 구분합니다. 다른 펌웨어나 포크는 표가 다를 수 있고, 표에 없는 밴드가 보고되면 ◀ ▶ 버튼으로 대체됩니다.
- **스테이션 목록과 메모리 슬롯**: 수신기는 `#` 입력을 그대로 되돌려 보내므로(에코), 슬롯 줄은 `$` 요청 뒤 1.2초 동안만 읽고(에코는 무시), 목록은 비우지 않고 다 받은 뒤에 한꺼번에 바꾸며, 방금 저장한 슬롯을 수신기가 보고하지 않으면 메시지로 알려 줍니다.
- **한계**: `F` 명령은 수신기의 현재 밴드 범위 안에서만 동작해서, 앱이 먼저 `B`로 슬롯의 밴드까지 수신기를 한 칸씩 넘기고(최대 40번, 매번 상태 줄 확인) `M`으로 모드를 맞춥니다. 앱의 스텝은 앱 쪽 튜닝 간격이며 수신기의 스텝 설정과는 별개입니다. 메모리 슬롯 저장은 슬롯 목록을 읽은 뒤에만 해서 기존 슬롯을 실수로 덮어쓰지 않습니다.
- **테스트**: 상태 줄 파싱과 명령 문자열은 단위 테스트(`ATSMiniRemoteTests`)로 확인합니다.

### 시뮬레이터에서 시험하기

시뮬레이터에는 블루투스가 없으므로, [`tools/mock_ats_mini.py`](tools/mock_ats_mini.py)(Python 3, 추가 설치 없음)의 모의 수신기에 Wi-Fi TCP로 연결합니다. 펌웨어 v2.45 소스를 따라 입력 프레이밍, `F`/`#` 입력의 에코, `Error:` 응답, 15개 필드 상태 줄, 28개 밴드 표, 슬롯 99개와 `#` 검증 규칙을 흉내 내고, Seek/Scan이 찾을 가짜 방송국(FM 89.1, 93.1, 101.7, 107.7, MW 1134, SW 9620 등)도 있습니다.

```bash
python3 tools/mock_ats_mini.py            # 127.0.0.1:60000에서 대기
python3 tools/mock_ats_mini.py -v         # 받은 명령을 모두 출력
python3 tools/mock_ats_mini.py --no-f     # F/# 명령이 없는 펌웨어처럼 동작(엔코더 대체 경로 시험)
python3 tools/mock_ats_mini.py --drop-memory-write   # #를 받고도 저장하지 않음(저장 실패 안내 시험)
```

앱에서 **기기 연결 → Wi-Fi TCP**를 열고 호스트에 `127.0.0.1`을 입력한 뒤 **연결**을 누르세요. 개발용 도구이며 실제 수신기가 아닙니다. 만든 근거인 펌웨어 소스만큼만 정확합니다.

### 빌드 방법

Xcode 프로젝트는 [XcodeGen](https://github.com/yonaskolb/XcodeGen)으로 생성합니다(`project.yml`). iOS 17 이상이 필요합니다.

```bash
brew install xcodegen
xcodegen generate
open ATSMiniRemote.xcodeproj
```

## 개발 계획

- [x] SwiftUI 라디오 제어 화면(다이얼, 이퀄라이저, 스테이션 캐러셀)을 구성합니다.
- [x] 기기 연결 화면을 구성합니다.
- [x] Core Bluetooth로 BLE 검색, 기기 선택, 연결 및 재연결을 구현합니다. (실기기 검증 필요)
- [x] ATS Mini의 Ad hoc 프로토콜로 주파수, 볼륨, 밴드와 수신 모드를 제어하고 수신기 상태를 표시합니다. (실기기 검증 필요)
- [x] 고급 설정(대역폭, AGC, 보정, 슬립, 엔코더, 메모리 슬롯)을 추가합니다. (실기기 검증 필요)
- [x] 스플래시 화면, 앱 아이콘, 영어/한국어 현지화를 추가합니다.
- [ ] 수신기 스텝 표시, 스크린샷, 테마 연동을 추가합니다.
- [x] BLE와 같은 명령을 쓰는 Wi-Fi TCP 연결과 시뮬레이터 시험용 모의 수신기.
- [x] Seek와 Scan.
- [ ] 실제 ATS Mini에서 BLE, 메모리 슬롯, 주파수 제어, Seek/Scan을 검증합니다.

`Ad hoc` 원격 제어 모드를 제공하는 [ESP32-SI4732 ATS Mini 펌웨어](https://github.com/esp32-si4732/ats-mini)를 기준으로 개발합니다. 지원 펌웨어 버전과 기기 조합은 iPhone과 ATS Mini 실기기에서 확인할 예정입니다.

## 향후 확장

Android 앱과 공통 통신 프로토콜 라이브러리를 개발하게 되면 각각 `ats-mini-android`와 `ats-mini-protocol`로 분리할 수 있습니다.
